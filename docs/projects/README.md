# Projects

One markdown file per feature or initiative. Suggested template:

```markdown
# <feature name>

**Status:** draft | in-progress | shipped | abandoned
**Owner:**
**Started:**
**Shipped:**

## Goal
What we're trying to do and why.

## Scope
In scope / out of scope.

## Design
Approach, key decisions, tradeoffs.

## Notes
Anything else worth recording.
```
